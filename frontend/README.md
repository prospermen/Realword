# Frontend

Frontend for the RealWorld-style blog application.

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Environment

Create `.env` from `.env.example` and point `VITE_API_BASE_URL` at the local backend:

```bash
VITE_API_BASE_URL=http://localhost:3000/api
```

See the repository root `README.md` for the full project setup.
